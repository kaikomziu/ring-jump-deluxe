# RING JUMP DELUXE - 輪くぐりジャンプ

自分はボール。タップ／クリック／スペースキーで羽ばたいて浮き、放っておくと落ちていく。フラッピーバード方式で、迫りくる輪の穴だけをくぐり抜けるハイスコア挑戦ゲーム。

公開URL: https://kaikomziu.github.io/ring-jump-deluxe/

## 遊び方
- タップ／クリック／スペースキー／↑キーで羽ばたく(ジャンプ)
- 輪の中心をくぐると「SWISH」ボーナス(+2点)
- 輪の枠・天井・地面に当たるとゲームオーバー
- スコアが上がるほど速度アップ＆輪の穴が狭くなる

## 構成
- `index.html` — ページ本体・UI
- `js/game.js` — ゲームロジック(canvas描画・物理・当たり判定)
- `js/version.js` — バージョン・更新履歴

## 開発
ローカル確認はリポジトリルートの `.claude/launch.json` の `ring-jump-deluxe` 設定を使用。
